¿Qué ocurre cuando abres una página web?

Una explicación sencilla del viaje entre tu navegador y el servidor que entrega una página.

El navegador actúa como cliente

Cuando visitas una dirección, tu navegador solicita los recursos necesarios para mostrar la página. En esta comunicación, el navegador actúa como cliente.

El servidor responde a la petición

El servidor recibe una petición HTTP y devuelve una respuesta. Esta incluye un código de estado y puede contener un recurso, como un documento HTML.

HTML y CSS tienen funciones diferentes

HTML estructura el contenido: títulos, párrafos, imágenes y enlaces. CSS define su presentación: colores, tamaños, espacios y distribución.

Un ejemplo con este blog

Al pulsar el enlace de esta entrada, el navegador solicita su página al servidor local de Eleventy. El servidor entrega el HTML y el navegador lo interpreta para mostrarlo en pantalla.
