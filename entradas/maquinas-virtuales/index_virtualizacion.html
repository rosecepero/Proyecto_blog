Qué es una máquina virtual

Una máquina virtual es un entorno que permite ejecutar un sistema operativo utilizando recursos de un ordenador físico, como memoria RAM, procesador y almacenamiento.

El anfitrión y el invitado

El ordenador físico que proporciona los recursos se llama anfitrión. El sistema operativo que se ejecuta dentro de la máquina virtual se llama invitado.

La función del hipervisor

El hipervisor es el software que permite crear y ejecutar máquinas virtuales y gestionar su acceso a los recursos del equipo físico.

  • Tipo 1: se ejecuta directamente sobre el hardware, sin un sistema operativo anfitrión convencional debajo.
  • Tipo 2: se ejecuta sobre un sistema operativo anfitrión, como una aplicación.

Un ejemplo con Windows y Ubuntu

Si utilizas VirtualBox en Windows para ejecutar Ubuntu, tu ordenador proporciona el hardware, Windows es el sistema operativo anfitrión, VirtualBox actúa como hipervisor de tipo 2 y Ubuntu es el sistema invitado.

Para qué sirve

Permite practicar con otros sistemas operativos y probar configuraciones en un entorno separado. Por ejemplo, puedes aprender comandos de Ubuntu sin sustituir la instalación de Windows de tu ordenador.

Los recursos son limitados

El anfitrión y las máquinas virtuales comparten los recursos físicos. Por eso, debemos dejar suficiente memoria RAM y capacidad de procesamiento para que el anfitrión siga funcionando correctamente.
